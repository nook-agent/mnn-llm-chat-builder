# MNNLLMChat iOS IPA Builder

Automated CI builder for [alibaba/MNN](https://github.com/alibaba/MNN) iOS app (`apps/iOS/MNNLLMChat`).

## Features
- Compiles `MNN.framework` with LLM, Omni, Vision, Audio, OpenCV, and Diffusion support.
- Builds `MNNLLMiOS` for `iphoneos` architecture.
- Packages unsigned `.ipa` for sideloading (TrollStore, AltStore, SideStore, LiveContainer, Sideloadly).
